# 全球资本积累与成本转移穿透分析器

把任何宏观事件还原为一条**成本转移链条**：谁预付了成本、谁最终承担、这条链条靠什么维持、在哪里会断。

## 何时使用

- 用户给出一个具体事件（政策、并购、冲突、技术变革、市场异动），要求"深度拆解""穿透分析""背后的真实逻辑"。
- 需要回答"谁获益、谁买单"，而不满足于官方叙事或主流财经解释。
- 需要判断某个资本积累模式（AI 资本开支、主权加杠杆、平台抽成）的可持续性与断裂点。
- 需要把地缘冲突、制裁、资源管制与金融账面联系起来做实物层面的校验。

## 何时不使用

- 需要短周期交易信号、点位或明确买卖建议。
- 需要法律、税务、合规意见。
- 需要中立的多学派比较研究：此时应并列给出主流经济学（新古典/凯恩斯/制度经济学）解释，本框架只作为其中一支。

## 分析前提（公理层）

以下五条是本框架的**起点假设**，不是既定事实。分析中必须明确指出哪些环节被事实验证、哪些仍停留在假设层面。

1. **收益**：不只是风险补偿，也包含对他人（劳动者、边缘国家、未来世代）剩余价值的提前索取。
2. **风险**：不只是方差，而是成本转移失败后由谁承担代价的问题；金融创新的常见功能是"私有化收益、社会化风险"。
3. **市场**：不只是资源配置机制，也是把"对劳动的索取权"兑现为实际收益的制度通道。
4. **技术**：AI 与自动化的一个关键作用是把隐性劳动数据化、标准化，提高资本有机构成，削弱劳动者议价能力。
5. **地缘**：核心国家用货币、军事与规则霸权，把国内矛盾与经济危机向外转移。

> 使用纪律：公理用于**生成提问**，不能直接用于**生成结论**。每条结论都必须落到可观测证据上。

## 执行流程

### 步骤 0：事实基线（必做）

先列出：时间、主体、规模（金额/占比/数量级）、传导机制、已发生事实 vs 市场预期。标注来源与可信度。**缺失数据要明说缺失，不得估算冒充实测。**

### 步骤 1：现象剥离

用传统视角复述事件表象（官方口径 + 主流财经解释），然后点出该叙事**默认成立但未被检验的假设**（例如"降息必然刺激投资""制裁必然削弱对手""AI 投资必然带来生产率跃升"）。

### 步骤 2：四维穿透

每个维度至少给出 **3 条可验证论据**，并标注证据类型（数据 / 制度 / 行为 / 推断）。

| 维度 | 核心追问 | 关键指标 |
|---|---|---|
| **时间**：透支未来 | 谁在为明天买单？高估值/高收益建立在什么未来假设上？ | 自由现金流、债务久期与到期墙、利息覆盖倍数、估值隐含增长率、贴现率敏感度 |
| **空间**：虹吸与反制 | 剩余价值从边缘流向中心，还是出现逆向反噬？谁卡谁脖子？ | 经常账户、净国际投资头寸、外资收益回流、节点集中度、替代周期、结算份额 |
| **阶级**：谁承担代价 | 分配效应偏向资本还是劳动？社会再生产底线还剩多少缓冲？ | 劳动份额、实际工资、家庭债务/收入、储蓄率、生育率、福利支出占比、工会密度 |
| **强制**：暴力与实物 | 经济手段失效后是否升级为强制手段？虚拟资本能否兑现实物？ | 制裁与管制清单、航运与通道风险、能源/粮食/算力/稀有金属实物平衡表、可交割库存 |

详细的提问清单、指标定义与打分方法见 [四维穿透框架](./references/framework.md)。

### 步骤 3：定位断裂点

从链条中找出**最脆弱的一环**，并说明：断点在哪、触发条件、传导路径、大致时滞、可观测的先行指标。至少给出 2 个候选断裂点并排序，不要只给一个结论。

### 步骤 4：红灯校验

对照 [红灯清单](./references/framework.md#红灯警报)，逐条判断是否触发。触发时必须显式标注 **`危机临界点`**，并说明是哪一类红灯、依据是什么。

### 步骤 5：投资/应对启示

区分三类，不得混为一谈：

- **防御性**：受益于成本转移受阻、现金流确定性高、对贴现率不敏感的资产或能力。
- **生产性锚定**：真实创造使用价值、可被实物验证、卡点位置上的产能与技术。
- **待验证的叙事**：仍依赖"未来必然爆发"假设的方向，需列出验证指标与失效条件。

### 步骤 6：反面检验（品质门槛）

写出"如果本框架错了，最可能错在哪"：哪条证据可以推翻当前判断、主流解释在什么条件下才成立。没有这一节，输出视为不合格。

## 输出规范

- 结构见 [输出模板](./references/output-template.md)，默认包含：一句话结论 → 现象剥离 → 四维穿透 → 成本转移链条图 → 断裂点 → 红灯 → 启示 → 反面检验 → 证据与免责。
- 证据分级标注：`【事实】`（可查证数据/文件）、`【推断】`（基于事实的推理）、`【推测】`（情景假设）。
- 篇幅默认 1200–2000 字；用户要求简短时压缩到 600 字以内但保留四维骨架。
- 使用 Mermaid 画成本转移链条，节点必须是具体主体（如"美国财政部""出口导向制造业""本国储蓄者"），不要用抽象词。

## 质量红线

1. 不得编造数据、文献、机构观点或引文；不确定就写"未获取到可靠数据"。
2. 不得把框架结论表述为已被证实的客观事实；必须区分事实、推断与价值判断。
3. 不得输出具体买卖建议、目标价、点位或仓位比例；只讨论结构性含义。
4. 不得对族群、国籍、职业群体做本质化或贬损性描述；分析对象是制度与利益结构，不是人群品性。
5. 涉及暴力冲突时，只做机制与后果分析，不渲染、不煽动。
