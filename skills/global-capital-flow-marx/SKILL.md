# 全球资本积累与成本转移穿透分析器

把任何宏观事件还原为**具体的矛盾运动**：先由事实确定对立面与斗争焦点，再判断主要矛盾及矛盾的主要方面，最后推演矛盾在既有条件下会以什么形式、朝哪个方向解决。

四维（时间/空间/阶级/强制）不是四个并列话题，而是核心矛盾展开、成本转移与矛盾积累的四个观察面。

## 何时使用

- 用户给出一个具体事件（政策、并购、冲突、技术变革、市场异动），要求"深度拆解""穿透分析""背后的真实逻辑"。
- 需要回答"核心矛盾是什么、谁获益、谁买单"，而不满足于官方叙事或主流财经解释。
- 需要判断某个资本积累模式（AI 资本开支、主权加杠杆、平台抽成）的可持续性、断裂点与可能走向。
- 需要把地缘冲突、制裁、资源管制与金融账面联系起来做实物层面的校验。

## 何时不使用

- 需要短周期交易信号、点位或明确买卖建议。
- 需要法律、税务、合规意见。
- 需要中立的多学派比较研究：此时应并列给出主流经济学（新古典/凯恩斯/制度经济学）解释，本框架只作为其中一支。

## 分析前提

### 辩证法的五条使用规则

1. **矛盾普遍存在，但每组矛盾有特殊性**：分析起点是找出具体对立面与斗争焦点，不是先评判好坏，也不得套用模板。
2. **主要矛盾决定性质**：多个矛盾并存时必须排序，指出哪一个支配其余矛盾；同时指出矛盾的主要方面在哪一侧。
3. **对立面相互依存、在一定条件下相互转化**：一方的强势会制造自身的否定条件；分析"强势如何转化为脆弱"。
4. **量变引起质变**：矛盾以成本转移、缓冲消耗、合法性流失的形式积累，越过临界点后以危机、制度变更或强制手段的形式跃变。
5. **内因是根本，外因是条件**：外部冲击通过内部结构起作用，不得把内部矛盾简单归因于外部敌人。

### 政治经济学起点假设

以下五条是**提问工具**，不是既定结论：

1. **收益**：不只是风险补偿，也包含对他人（劳动者、边缘国家、未来世代）剩余价值的提前索取。
2. **风险**：不只是方差，而是成本转移失败后由谁承担代价；金融创新的常见功能是"私有化收益、社会化风险"。
3. **市场**：不只是资源配置机制，也是把"对劳动的索取权"兑现为实际收益的制度通道。
4. **技术**：AI 与自动化的一个关键作用是把隐性劳动数据化、标准化，提高资本有机构成，削弱劳动者议价能力。
5. **地缘**：核心国家用货币、军事与规则霸权，把国内矛盾与经济危机向外转移。

> 使用纪律：上述规则与假设用于**生成提问**，不能用于**生成结论**。每条结论都必须落到可观测证据上；证据不足时写"无法判定"。不得把"矛盾"当作标签贴完就走，必须写出主体、对象与机制。

## 执行流程

### 步骤 0：事实基线（必做）

先列出：时间、主体、规模（金额/占比/数量级）、传导机制、已发生事实 vs 市场预期。标注来源与可信度。**缺失数据要明说缺失，不得估算冒充实测。**

事实基线的作用是限定矛盾分析的范围：先确定"哪些事实已经发生"，再讨论"什么在对抗什么"。

### 步骤 1：矛盾识别

从事实中提取 **2–4 组矛盾候选**，每组必须写成：

> **A 与 B 围绕 X 的对立**（A、B 是具体主体或结构力量，X 是争夺对象：剩余价值、定价权、通道、规则、时间）

要求：

- 对立双方都能在事实基线中找到对应物，不得虚构。
- 写明双方**相互依存的条件**（B 为什么暂时离不开 A）。
- 写明**斗争焦点**与当前力量对比。

### 步骤 2：主要矛盾判定

对候选矛盾排序，选出**主要矛盾**，并指出**矛盾的主要方面**。排序依据：

1. **支配性**：哪组矛盾的变化会改变其余矛盾的走向？
2. **传导力**：哪组矛盾能解释成本转移链条的主路径？
3. **激化速度**：哪组矛盾正在以可观测的速度积累（量变指标）？
4. **可证伪性**：哪组矛盾能被数据支持或被数据推翻？

输出必须明确回答：**当前的核心矛盾是什么；矛盾的主要方面在哪一侧；为什么其他矛盾是次要的。**

### 步骤 3：四维展开

四维是主要矛盾的表现面。每个维度至少给出 **3 条可验证论据**，并标注证据类型（数据 / 制度 / 行为 / 推断）。

| 维度 | 核心追问 | 关键指标 |
|---|---|---|
| **时间**：透支未来 | 矛盾如何以"预支未来收入流"的方式被推迟？谁持有久期风险？ | 自由现金流、债务久期与到期墙、利息覆盖倍数、估值隐含增长率、贴现率敏感度 |
| **空间**：虹吸与反制 | 矛盾如何在中心与边缘之间转移？谁卡谁脖子？反噬在哪？ | 经常账户、净国际投资头寸、外资收益回流、节点集中度、替代周期、结算份额 |
| **阶级**：谁承担代价 | 矛盾的成本落在哪个阶级的资产负债表和社会再生产底线上？ | 劳动份额、实际工资、家庭债务/收入、储蓄率、生育率、福利支出占比、工会密度 |
| **强制**：暴力与实物 | 经济手段失效后，矛盾是否升级为强制手段？虚拟资本能否兑现实物？ | 制裁与管制清单、航运与通道风险、能源/粮食/算力/稀有金属实物平衡表、可交割库存 |

详细的提问清单、指标定义与打分方法见 [矛盾分析与四维框架](./references/framework.md)。

### 步骤 4：矛盾运动与临界点

回答三个问题：

1. **量变在哪积累**：列出 3–5 个可观测的缓冲消耗指标（金融、实物、财政、社会、政治、外部）。
2. **质变的临界条件**：缓冲耗尽 + 触发事件 + 传导路径。至少给出 **2 个候选断裂点**并排序，写明时滞与先行指标。
3. **是否已到临界**：对照 [质变临界信号](./references/framework.md#8-质变临界信号红灯警报) 逐条校验；触发时显式标注 **`危机临界点`**。

### 步骤 5：走向推演

给出 **2–3 种可能走向**，其中必须包含一个**基准走向**。每种走向都要写清：

- **解决形式**：一方压倒另一方 / 对立面重组为新形态 / 矛盾向外转移 / 制度性调节缓和。
- **触发条件**：哪些前提同时成立才会走这条路径。
- **时间尺度**：季度级、年度级还是多年级。
- **先行指标**：哪些可观测变量会先动。
- **置信度**：高 / 中 / 低，并说明理由。

不得只给单一宿命结论（"必然崩溃""必然胜利"），也不得用辩证法标签替代机制与证据。

### 步骤 6：启示

按走向分情景给出结构性含义，区分三类，不得混为一谈：

- **跨走向的防御性**：在多数走向下都能保住购买力与现金流的结构性位置。
- **生产性锚定**：真实创造使用价值、可被实物验证、位于卡点上的产能与技术。
- **待验证的叙事**：只在特定走向下成立、仍依赖"未来必然爆发"假设的方向，需列出验证指标与失效条件。

### 步骤 7：反面检验（品质门槛）

写出三件事：

1. "如果本框架错了，最可能错在哪"（哪一步推理、哪条假设）。
2. 哪条证据可以推翻当前的核心矛盾判定与走向判断。
3. 主流解释在什么条件下才成立。

没有这一节，输出视为不合格。

## 输出规范

- 结构见 [输出模板](./references/output-template.md)，默认包含：一句话结论 → 事实基线 → 核心矛盾 → 四维展开 → 成本转移链条图 → 矛盾运动与临界点 → 可能走向 → 启示 → 反面检验 → 证据与免责。
- **核心矛盾必须写成"A 与 B 围绕 X 的对立"**，并注明矛盾的主要方面；不得只用"存在风险""结构失衡"等模糊表述。
- **走向必须条件化**：至少两种，含基准走向、解决形式、触发条件、时间尺度、先行指标与置信度。
- 证据分级标注：`【事实】`（可查证数据/文件）、`【推断】`（基于事实的推理）、`【推测】`（情景假设）。
- 篇幅默认 1200–2000 字；用户要求简短时压缩到 600 字以内但保留"核心矛盾 + 四维骨架 + 基准走向"。
- 使用 Mermaid 画成本转移链条，节点必须是具体主体（如"美国财政部""出口导向制造业""本国储蓄者"），不要用抽象词。

## 质量红线

1. 不得编造数据、文献、机构观点或引文；不确定就写"未获取到可靠数据"。
2. 不得把框架结论表述为已被证实的客观事实；必须区分事实、推断与价值判断。
3. 不得输出具体买卖建议、目标价、点位或仓位比例；只讨论结构性含义。
4. 不得对族群、国籍、职业群体做本质化或贬损性描述；分析对象是制度与利益结构，不是人群品性。
5. 涉及暴力冲突时，只做机制与后果分析，不渲染、不煽动。
6. 不得把"必然崩溃/必然胜利"当作结论：走向必须是条件性的，并给出可证伪的先行指标。
7. 不得用"矛盾"一词替代具体机制：每处矛盾判断都要落到主体、对象与证据。
