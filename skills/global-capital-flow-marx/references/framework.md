## 1. 矛盾识别与主要矛盾判定

### 1.1 矛盾识别：从事实到对立面

不要先给结论再找证据。先列出事实基线中的**利益、约束与时间表冲突**，再归纳为矛盾候选。

矛盾陈述的标准格式：

> **A 与 B 围绕 X 的对立**：A 要求……，B 要求……；双方相互依存的条件是……；当前斗争焦点是……。

- A、B：具体主体或结构力量（如"债务滚续的财政需求"与"剩余价值创造能力"），不能是"市场""人性"等空泛词。
- X：争夺对象——剩余价值、定价权、通道、规则制定权、时间。
- 相互依存条件：说明为什么双方尚未决裂（例如"低利率同时维持债务可持续与资产估值"）。
- 每组矛盾都必须能在事实基线中找到对应证据；找不到的降级为【推测】或删除。

常见矛盾类型（用于生成候选，不用于套结论）：

| 类型 | 表现形式 |
|---|---|
| 生产力与生产关系 | 技术能力已具备，但分配与准入规则阻碍其被使用 |
| 生产与实现 | 产能与供给扩张，但有支付能力的需求不足 |
| 资本增殖与霸权护持 | 企业需要市场与利润，国家需要封锁与对抗 |
| 虚拟资本与实物生产 | 账面估值依赖未来现金流，实物产能与交割能力跟不上 |
| 中心与边缘 | 核心国输出成本，边缘国承受调整 |
| 资本与劳动 | 成本通过工资、就业、工时、福利转嫁 |
| 代际 | 当代透支未来税基、资源与生态 |
| 经济基础与上层建筑 | 经济结构已变，制度与合法性叙事未变 |

### 1.2 主要矛盾判定

多个矛盾并存时，必须排序并说明理由。排序标准：

1. **支配性**：哪组矛盾的变化会改变其余矛盾的走向？
2. **传导力**：哪组矛盾能解释成本转移链条的主路径？
3. **激化速度**：哪组矛盾正以可观测速度积累（量变指标在恶化）？
4. **可证伪性**：哪组矛盾能被数据支持或被数据推翻？

输出要求：

- 明确写出**主要矛盾**（一句话，含 A、B、X）。
- 明确写出**矛盾的主要方面**：当前哪一侧占支配地位，以及这种支配地位依赖什么条件。
- 列出**次要矛盾**及其与主要矛盾的关系（被支配、被掩盖、可能转化）。
- 说明主要矛盾是否正在发生变化；如果证据不足，写"无法判定"。

### 1.3 矛盾的对抗性

判断矛盾是对抗性还是非对抗性，决定它更可能以什么形式解决：

| 性质 | 特征 | 可能解决形式 |
|---|---|---|
| 对抗性 | 一方所得以另一方生存条件受损为前提；无共同可接受的调整空间 | 危机爆发、强制手段、制度断裂、一方压倒另一方 |
| 非对抗性 | 存在双方都能接受的成本分担与规则调整空间 | 改良、再分配、制度性调节、对立面重组 |
| 转化中 | 原本可调节，但因缓冲耗尽或政治极化转向对抗 | 取决于临界条件与政策选择 |

判定依据是**成本分担空间**与**政治可行性**，不是双方的主观意图。

### 1.4 核心机制：私人资本增殖—实现矛盾

这是本框架的底层校验：任何事件都要问，它是在缓解还是在激化"增殖率要求压低劳动份额"与"实现要求总需求足够大"之间的矛盾。

**机制链条**

1. **增殖率叙事**：私人资本按预期增殖率（利润率/剩余价值率的表象）组织投资；叙事通过估值、信贷与资产价格被资本化。
2. **金融的时间—空间转换**：信用把未来剩余价值流贴现为当下资本，使资本在空间上集聚；这是"时间向空间的转移"。
3. **现金分发的双重性**：资本以工资、采购、投资支出把部分货币分发给劳动者与供应商，既构建新产能，又形成实现条件；金融资产与虚拟资本则停留在流通领域。
4. **增殖—实现矛盾**：提高剩余价值率要求压低工资份额；但产品实现要求劳动总收入足够大。二者方向相反。资本有机构成提高会进一步压缩可变资本占比。
5. **人口边界**：资本积累的规模最终受总人口、劳动人口与有支付能力需求约束；总需求的基本盘是就业者的劳动收入（劳动人口 × 就业率 × 工资水平），劳动份额下降、人口增长放缓、失业上升都会收紧边界。
6. **边界的转移**：金融化（时间）、出口与全球化（空间）、福利支出（公共部门）、帝国主义（强制）可以推迟边界，但不能取消它。

前五步构成**正反馈回路**：叙事吸引资本，资本推动空间集聚与现金分发，现金分发扩大产能与需求，更大的资本规模又强化叙事。第六步是**负反馈边界**：压低劳动份额会削弱总需求，回路越强，越接近人口与收入边界。

**校验指标**

| 环节 | 指标 | 读法 |
|---|---|---|
| 增殖率叙事 | 估值隐含增长率、利润率、资本化率 | 叙事是否已计入价格 |
| 金融时间转移 | 信贷/GDP、债务/GDP、家庭债务/收入、资产价格/收入 | 未来是否被提前透支 |
| 空间集聚 | 产业链集中度、城市/区域资本集中度、FDI 流向 | 资本在何处集聚 |
| 现金分发 | 劳动收入份额、工资增速、转移支付 | 多少流入生产与消费 |
| 人口边界 | 总人口、劳动年龄人口、劳动参与率、失业率 | 总需求的基本盘 |
| 实现压力 | 产能利用率、库存、企业利润率、破产率 | 价值实现是否受阻 |
| 边界转移 | 出口依存度、贸易顺差、政府赤字、福利支出 | 矛盾被推向哪里 |

**四种出路（对应第 7 节走向）**

| 出路 | 机制 | 代价 |
|---|---|---|
| 空间外移 | 开拓外部市场、产业链扩张、霸权与战争 | 外部国家承担调整成本，反噬风险上升 |
| 时间外移 | 信贷扩张、债务化、通胀、资产泡沫 | 未来税基与储蓄者承担，金融脆弱性上升 |
| 价值毁灭 | 危机、破产、失业、战争 | 资本与劳动同时受损，但弱者承担更多 |
| 制度调节 | 提高劳动份额、再分配、公共投资、缩短工时 | 资本端阻力大，需要政治可行性 |

**常见误判**

- 把金融化当作矛盾的解决：它只是把实现问题推向未来，并积累金融脆弱性。
- 把外部市场当作无限空间：空间外移会遭遇地缘反制与外部需求上限。
- 把人口边界当作机械公式：分配结构、国家支出与技术变化会改变边界的位置。

> 注意：人口边界是**趋势性约束**，不是机械公式。总人口并非直接决定资本规模，而是通过劳动收入—总需求—实现条件起作用；金融化、国家支出、外部市场与分配结构都会改变边界的位置。分析时必须给出当期数据，不得直接套用"人口决定论"。

## 2. 时间维度：透支未来与虚拟资本

### 核心追问

**谁在为明天买单？当前收益是存量剩余价值的再分配，还是对未来收入流的提前资本化？**

> 矛盾在这一维度的表现：把当前无法解决的成本推给未来收入流，用估值与债务久期换取时间。

### 提问清单

1. **现金流来源**：收益来自经营现金流，还是来自资产重估与再融资？
2. **资本化率**：估值隐含的永续增长率、利润率、渗透率假设分别是多少？取历史下限重算会怎样？
3. **久期结构**：债务久期、到期墙分布、浮动利率占比、再融资成本变动 100bp 的利息影响。
4. **贴现幻觉三件套**：
   - 技术奇点叙事（"这一代技术必然带来生产率跃升"）
   - 债务滚续叙事（"主权不会违约，因为可以本币化"）
   - 人口/移民红利叙事（"劳动力缺口会被自动填补"）
5. **谁持有久期风险**：养老金、保险公司、银行表内、私募信贷、散户杠杆 ETF、主权基金。
6. **反身性**：资产价格上涨本身是否成为抵押品扩张和信贷投放的前提？

### 关键指标

| 指标 | 读法 |
|---|---|
| 自由现金流（FCF）与净利润的差额 | 长期背离说明利润依赖应计与资本化 |
| 利息覆盖倍数（EBIT/利息） | 低于 2 意味着利率上行即失去缓冲 |
| 债务加权久期 | 久期越长，对贴现率越敏感 |
| 隐含永续增长率 | 高于名义 GDP 增速假设时要标注风险 |
| 期限溢价与信用利差 | 同时走阔说明"无风险"与"盈利"两个假设同时受损 |
| 资本开支/折旧比 | 长期远高于 1 说明在为未来产能预付 |

### 常见误判

- 把"市值高"直接等同于"泡沫"：高市值也可能对应真实现金流，必须落到 FCF 与资本回报率。
- 把"债务/GDP 高"直接等同于"不可持续"：还要看币种结构、久期、利率与债权人身份。

## 3. 空间维度：全球虹吸与产业链阵地

### 核心追问

**剩余价值往哪个方向流？中心国家在抽取边缘国家，还是出现逆向反噬？谁掌握卡点？**

> 矛盾在这一维度的表现：把国内成本向外转移，同时承受反噬；卡点决定谁先撑不住。

### 提问清单

1. **价值流向地图**：贸易账户、 primary income（投资收益）账户、净国际投资头寸三者是否同向？
   - 注意：经常账户逆差国可能同时是投资收益顺差国，这才是"铸币税 + 资产收益"双通道的证据。
2. **产业链卡点矩阵**：每个关键节点填一行。

   | 节点 | 全球集中度（CR3） | 替代周期 | 库存缓冲（周/月） | 卡住谁 | 被卡方反制手段 |
   |---|---|---|---|---|---|
   | 例：先进制程代工 | | 3–5 年 | | | |

3. **成本转嫁路径**：上游 → 中游 → 下游 → 终端消费者 / 劳动者。谁有定价权，谁只能压缩毛利或工资。
4. **货币与规则**：
   - 离岸美元供给、央行互换额度使用量
   - 跨境结算份额变化（SWIFT / CIPS / 本币互换）
   - 制裁工具化程度（实体清单、次级制裁、资产冻结）
5. **逆向反噬检验**：核心国使用卡点后，自身是否承受通胀、供应链回流的资本成本、信用折价。

### 关键指标

| 指标 | 读法 |
|---|---|
| 投资收益差额 / GDP | 衡量"索取权"而非"贸易"的净流向 |
| 净国际投资头寸（NIIP） | 负债以本币计价、资产以外币计价时，贬值即减债 |
| 关键节点 CR3 与替代周期 | 替代周期 > 库存缓冲 → 短期无解 |
| 结算货币份额 | 变化慢，但方向比水平更重要 |
| 航运运价与保险费率 | 物理阻断的最早价格信号 |

### 常见误判

- 把"脱钩"当成"断裂"：多数情况是**路径重组 + 成本上升**，不是消失。
- 只看货物贸易，忽略服务贸易与投资收益，容易得出相反的流向结论。

## 4. 阶级维度：剩余价值剥削与成本转嫁

### 核心追问

**政策/事件的分配效应把成本压给了谁？社会再生产底线还剩多少缓冲？**

> 矛盾在这一维度的表现：成本最终落在哪个阶级的资产负债表与社会再生产底线上，以及该阶级的承受力还剩多少。

### 提问清单

1. **财政端**：减税落在资本还是劳动？税基是直接税还是间接税？化债靠通胀、削减公共服务，还是向资本征税？
2. **货币端**：宽松推高资产价格（持有者获益），紧缩压制工资与就业（劳动者承担）；实际利率为负时，谁补贴谁？
3. **监管端**：准入、牌照、数据归属规则改变后，租金从哪一方转移到哪一方？
4. **社会再生产底线**：
   - 实际工资增速 vs 生产率增速
   - 家庭债务/可支配收入、储蓄率、信用卡与消费贷拖欠率
   - 生育率、预期寿命、心理健康与劳动参与率
   - 住房支出占收入比、通勤时间
5. **阶层重构**：独立专业服务者被降格为平台附庸的三个标志
   - 计价方式从"项目/服务"变为"计件/流量"
   - 评价权从同行/客户转移到平台算法
   - 数据与客户关系归属平台而非个人
6. **组织与政治反馈**：工会密度、罢工频次、选举极化、福利支出占比、移民政策。

### 关键指标

| 指标 | 读法 |
|---|---|
| 劳动收入份额 | 长期下行是"分配端"最直接的证据 |
| 生产率 - 实际工资增速缺口 | 缺口扩大 = 增长成果未传导 |
| 家庭债务/收入 | 高于 100% 后，利率变动直接冲击消费 |
| 顶层 1% 财富份额 | 与资产价格周期的同步性 |
| 社会支出/GDP | 缓冲垫厚度 |

### 常见误判

- 把"失业率低"当作"劳动者议价能力强"：还要看就业质量、工时、合同类型与实际工资。
- 把个体行为（不婚、不育、躺平）道德化：先看约束条件是否变化。

## 5. 强制维度：地缘暴力与物理阻断

### 核心追问

**当关税、利率、补贴等经济手段无法完成成本转移时，是否升级为强制手段？账面财富能否兑现实物？**

> 矛盾在这一维度的表现：经济手段无法完成成本转移时，矛盾升级为强制与实物阻断；此时账面财富与实物可获得性开始分离。

### 暴力梯度（由低到高）

规则修订 → 关税与非关税壁垒 → 金融制裁 → 出口管制与投资审查 → 长臂管辖与次级制裁 → 资产冻结与断供 → 军事干预与航道封锁

判断升级的关键：**成本转移的失败程度**，而不是对方的"意图"。

### 提问清单

1. **梯度定位**：当前事件处于哪一级？过去 12 个月是否在升级？
2. **实物平衡表**（抛开金融账面）：

   | 品类 | 供给集中度 | 可交割库存 | 替代产能投产时间 | 战略储备 | 硬缺口 |
   |---|---|---|---|---|---|
   | 能源 / 粮食 / 算力 / 稀有金属 / 航运舱位 | | | | | |

3. **兑现能力**：纸面库存 vs 可交割库存；期货合约与实物的比率；交割地集中度。
4. **物流枢纽**：霍尔木兹、马六甲、苏伊士/红海、巴拿马、黑海、关键海底光缆与数据中心集群。
5. **升级风险**：误判、同盟义务、国内政治压力导致螺旋上升的概率。

### 常见误判

- 把"制裁宣布"当作"制裁生效"：要看执行能力、规避网络与灰色渠道。
- 把"金融资产价格"当作"实物可获得性"：两者可以长期背离，直到交割日。

## 6. 矛盾运动：量变、质变与断裂点

### 6.1 量变积累指标

矛盾不会因"看起来严重"而爆发，只会因缓冲耗尽而爆发。至少跟踪 3–5 项：

| 缓冲类型 | 量变指标 | 耗尽信号 |
|---|---|---|
| 金融缓冲 | 现金储备、授信额度、利息覆盖倍数 | 再融资失败、评级下调、抵押品追缴 |
| 实物缓冲 | 库存周数、战略储备、替代产能投产进度 | 库存低于替代周期 |
| 财政缓冲 | 利息支出占比、赤字率、期限溢价 | 拍卖尾部扩大、评级展望下调 |
| 社会缓冲 | 家庭储蓄率、拖欠率、社会支出 | 实际工资负增长 + 福利削减同时出现 |
| 政治缓冲 | 执政联盟稳定性、选举极化、罢工频次 | 无法组成多数、政策反复、街头对抗 |
| 外部缓冲 | 外汇储备、互换额度、经常账户 | 储备快速下降、货币贬值失控 |

### 6.2 断裂点目录

按可能性排序时需要给出触发条件与先行指标。

| # | 断裂点 | 触发条件 | 先行指标 |
|---|---|---|---|
| 1 | AI 资本开支 vs 变现能力 | 折旧与电力成本上升、推理价格战、企业采购放缓 | 数据中心空置率、GPU 租赁价格、云厂商资本开支指引 |
| 2 | 主权债务再融资 | 期限溢价走阔 + 拍卖尾部扩大 | 投标倍数、一级交易商承接比例、CDS |
| 3 | 去美元化侵蚀美债需求 | 官方储备中美元占比持续下降 + 外资持仓减少 | TIC 数据、央行购金量、互换额度使用 |
| 4 | 底层承受力见底 | 实际工资负增长 + 福利削减 + 家庭债务高位 | 拖欠率、罢工、消费降级指标、社会支出削减 |
| 5 | 产业链替代慢于封锁 | 替代周期 > 库存缓冲 | 库存周转天数、设备交付周期、良率爬坡 |
| 6 | 私募信贷与商业地产 | 再融资墙 + 估值下调触发追加抵押 | 到期规模、估值下调频率、基金赎回限制 |
| 7 | 跨境套息杠杆反转 | 利差收窄 + 波动率跳升 | 日元/瑞郎持仓、交叉货币基差 |
| 8 | 人口与社保 | 抚养比上升 + 财政转移支付刚性 | 养老金缺口、医疗支出增速、移民净流入 |

### 6.3 断裂点到走向的衔接

每个断裂点都要回答：断裂后由谁承担损失、哪一方被迫改变行为、制度是否随之调整。断裂点不是终点，而是矛盾解决形式的入口。

## 7. 走向推演

### 7.1 四种基本解决形式

| 形式 | 机制 | 典型信号 | 谁承担成本 |
|---|---|---|---|
| 一方压倒另一方 | 强者用市场、财政或强制手段迫使对方接受调整 | 对方储备耗尽、被迫签约、政策转向 | 失败一方及其底层 |
| 价值毁灭 | 危机、破产、失业、战争消灭部分资本与生产能力 | 大规模违约、破产潮、失业率跳升、冲突升级 | 资本与劳动同时受损，弱者承担更多 |
| 对立面重组为新形态 | 危机后形成新的制度安排或技术—产业组合 | 破产清算、监管重构、新联盟 | 旧结构中的既得利益者 |
| 矛盾向外转移（空间/时间） | 空间：外部市场、产业链、霸权；时间：信贷、债务、通胀 | 贸易与金融制裁升级、资本管制、债务扩张 | 外部国家、未来税基与储蓄者 |
| 制度性调节缓和 | 再分配、债务重组、公共投资、规则改革 | 税收调整、债务减免、福利扩张 | 有支付能力的资本与高收入群体 |

### 7.2 走向推演的最低要求

至少给出 2–3 种走向，其中一个是**基准走向**（概率最高，不等于必然）。每种走向必须包含：

1. **解决形式**：上表四类中的哪一类或哪几类组合。
2. **触发条件**：哪些前提必须同时成立。
3. **时间尺度**：季度级 / 年度级 / 多年级。
4. **先行指标**：哪些变量会最先变化。
5. **对不同主体的影响**：获益方、承担方、被牺牲方。
6. **置信度**：高 / 中 / 低 + 理由。
7. **可证伪点**：出现什么证据说明这条走向不成立。
8. **与增殖—实现机制的关系**：这条走向是在空间/时间上推迟边界、通过价值毁灭重置资本，还是通过制度调节提高劳动份额？

### 7.3 基准走向的选择规则

- 优先选择**与当前力量对比和制度约束一致**的走向，而不是"最合理"或"最道德"的走向。
- 如果两种走向条件接近，写"分歧走向"，并列出区分二者的关键观察窗口。
- 不得输出单一宿命结论；也不得用"历史必然"替代机制。
- 走向判断必须能追溯到第 1 节的主要矛盾与第 6 节的量变指标。

## 8. 质变临界信号（红灯警报）

出现以下特征时，必须显式标注 **`危机临界点`**，并写明依据。阈值需按当期数据校准。红灯不是走向本身，而是矛盾进入质变阶段的信号；触发后仍需在第 7 节给出走向。

### 经济红灯

- 长端国债收益率与股指**同时**上冲（无风险资产信用受损 + 盈利预期极度集中）。
- 单一主题（如 AI 相关）对指数盈利增长的贡献超过 50%，且融资结构中存在隐性债务或表外杠杆。
- 信用利差走阔而政策利率下行（流动性传导失效）。

### 政治红灯

- 税收结构无法向资本端调整（直接税、资本利得税、财富税推不动），化债只能靠通胀或削减公共服务。
- 财政刚性支出（利息 + 社保 + 国防）占比挤压可自由裁量支出至极限。

### 地缘红灯

- 物流枢纽（霍尔木兹、马六甲、苏伊士、巴拿马）或关键实物产能（稀土、先进制程、氖气、粮食）出现**物理性断供**。
- 虚拟资本无法兑现为实物：交割违约、出口禁令覆盖在途货物。

### 社会红灯

- 技术替代高薪岗位的速度快于再分配机制（UBI、国资划转社保、再培训）的覆盖速度。
- 中产阶层出现"无产阶级化"的量化迹象：资产端缩水 + 收入端平台化 + 保障端缺失同时发生。

## 9. 压力打分卡（可选）

对主要矛盾在四个维度上的表现强度各按 0–3 打分，用于横向比较不同事件或不同时点；打分前先完成第 1 节的主要矛盾判定。

| 分数 | 含义 |
|---|---|
| 0 | 结构稳健，缓冲充足 |
| 1 | 存在张力，但有政策空间 |
| 2 | 缓冲接近耗尽，依赖单一条件维持 |
| 3 | 已出现断裂前兆，自我修复能力丧失 |

总分 0–12：

- 0–3：常态运行
- 4–6：张力累积，需跟踪
- 7–9：高脆弱，任一冲击可能触发连锁
- 10–12：**危机临界点**

打分必须附一句理由，禁止只给数字。

## 10. 证据标注规则

| 标注 | 定义 | 例子 |
|---|---|---|
| `【事实】` | 可查证的公开数据、法规文本、财报科目 | "某国 2026 年 Q2 经常账户顺差占 GDP 3.1%（来源：央行，2026-08）" |
| `【推断】` | 由事实经明确逻辑推导 | "若久期结构不变，再融资成本上升 150bp 将使利息支出占比翻倍" |
| `【推测】` | 情景假设，需条件句表述 | "若出口管制扩展至设备维护，替代周期可能延长至 5 年以上" |

禁止把 `【推测】` 写成 `【事实】` 的语气。
